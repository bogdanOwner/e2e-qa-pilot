# Diary page

## States

- Personal Space shows the Mood Diary section and the Awesome button.
- Create Diary Entry is a dialog. The mood line reads `Mood: Awesome`. Thoughts is a labeled text field. Save closes the dialog.
- After save, the status line reads `Your Diary entry successfully created!`. The preview list contains the thoughts text. A control labeled `chart dot` is visible.
