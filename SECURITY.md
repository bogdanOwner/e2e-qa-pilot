# Security policy

## Supported versions

Security fixes land on the latest release published to npm and on the default branch.

## Reporting a vulnerability

Report a vulnerability privately through [GitHub Security Advisories](https://github.com/bogdanOwner/e2e-qa-pilot/security/advisories/new).

Please do not open a public issue for a security report.

This project does not store credentials. The MCP server makes no network requests. It only returns instruction text. Review the diff and the pull request your assistant opens, because that part is outside this package.
